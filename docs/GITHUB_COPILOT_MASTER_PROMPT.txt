Folder rules (enforce, do not violate):
- `assets/` → static resources only, never logic.
- `components/` → reusable UI only, never page-level logic, never API calls.
- `pages/` → complete screens assembled from components.
- `services/` → API communication only, never UI state.
- `hooks/` → all business logic, loading/error/mutation handling lives here.
- `context/` → global state only (auth, theme).
- `constants/` → routes, API URLs, localStorage keys, regex, app config.
- `utils/` → pure functions, zero React code.
- `types/` → all interfaces/types.
- `lib/` → third-party config only (axios instance, query client).
- Architecture direction is one-way only: `Pages → Components → Hooks → Services → Backend`. Never let a component import a service directly.
