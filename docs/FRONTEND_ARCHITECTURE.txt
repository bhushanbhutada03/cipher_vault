# Project Name

Secure Credential Organizer UI

---

# Purpose

Build a modern, premium, responsive frontend for the existing Spring Boot backend.

The application allows users to securely store and manage website credentials with AES encrypted passwords.

The UI should feel like a modern SaaS application rather than a college project.

Design Inspiration:

• Apple
• Proton Pass
• Bitwarden
• 1Password
• Linear
• Vercel

Avoid generic admin dashboards.

The goal is to make recruiters think:

"This looks like a real product."

# Component Design Principles

Every component must satisfy these rules.

1.

Single Responsibility Principle

One component = One job.

Example

CredentialCard

Only display a credential.

Do NOT call APIs.

Do NOT manage authentication.

---

2.

Reusable

If a component can be reused twice,

move it into common/.

---

3.

Presentational Components

Components should mainly render UI.

Business logic belongs inside hooks.

---

4.

No API Calls

❌ Never

axios.get()

axios.post()

inside components.

Always use

Custom Hook

↓

Service

↓

Backend

---

5.

Maximum Component Size

Target

<150 lines

250 lines

Split if necessary.

## PART 5 — Authentication, Context & Session Architecture

---

# Authentication Overview

Authentication is based on JWT.

Backend is responsible for

• Login
• Registration
• Password Reset
• OTP Verification
• JWT Generation
• JWT Validation

Frontend is responsible for

• Store Token
• Check Login State
• Protect Routes
• Logout
• Redirect User
• Session Expiry Handling

Never validate JWT manually.

Backend is the source of truth.
